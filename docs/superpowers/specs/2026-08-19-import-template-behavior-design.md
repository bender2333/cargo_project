# Excel 导入与模板配置功能行为稿

- 日期：2026-08-19
- 文档类型：产品功能与行为预期
- 状态：已确认，作为模板重构的产品行为基准
- 适用范围：Excel/CSV 导入、字段映射、导入预览、导入模板管理

> 本文只描述用户能做什么、系统应如何反馈以及最终业务结果，不规定代码结构或技术实现。

## 1. 功能定位

Excel 导入用于把外部货物表转换为当前工作台可直接装箱的货物清单。

模板配置用于保存某一种固定表格格式的识别规则，使用户再次导入相同来源的文件时，不需要重新配置表头、字段和单位。

该功能必须解决三个问题：

1. 用户在导入前能看懂系统识别了什么。
2. 错误数据不能以“导入成功”的形式进入货物清单。
3. 已确认的标签、尺寸和业务限制在装箱、2D、3D、分层、明细与导出中保持一致。

## 2. 功能组成

| 功能 | 用户目的 | 系统结果 |
| --- | --- | --- |
| 文件导入 | 选择外部 Excel 或 CSV | 读取文件后进入本次导入的模板选择，不直接修改货物 |
| 模板选择 | 选择已有识别规则，或明确选择不使用模板 | 在当前导入确认中应用模板；不使用模板时进入空白手动映射 |
| 字段映射 | 指定每一列代表什么 | 生成可检查的标准货物预览，必填映射在字段名前显示 `*` |
| 单位设置 | 确认尺寸是毫米还是厘米 | 显示换算后的毫米尺寸 |
| 数据预览 | 检查原始值与导入结果 | 在确认前发现错误、警告和遗漏 |
| 保存为模板 | 保存未选择模板时完成的映射 | 新建一个可复用模板，但不执行导入 |
| 更新模板 | 保存对已选模板映射的明确修改 | 更新原模板，但不执行导入 |
| 另存为模板 | 保留原模板并保存修改后的映射 | 要求输入新的唯一名称并创建新模板，但不执行导入 |
| 确认导入 | 使用本次识别结果 | 整体替换当前货物清单，并使旧装箱结果失效 |
| 模板管理 | 独立维护模板的新建、编辑、重命名和删除 | 保持常用供应商或客户表格格式可维护 |
| 导入日志 | 查看本次处理结果 | 显示成功数、警告、跳过行和换算信息 |

## 3. 用户主流程

### 3.1 选择文件

用户从工作台选择 `.xlsx`、`.xls` 或 `.csv` 文件。

预期行为：

- 系统读取文件后先进入本次导入确认中的“模板选择”阶段。
- 文件选择本身不改变当前货物清单。
- 系统只读取当前约定的第一个工作表；不会把多个工作表静默合并。
- 文件为空、无法读取、解析超时或超过导入上限时，不进入模板选择，直接显示明确失败原因。
- 超限文件整批拒绝，不截断后伪装为完整导入。

### 3.2 模板选择

文件解析成功后，导入确认首先展示模板选择。模板选择属于本次导入确认的一部分，不要求用户跳转到独立的模板管理页。

用户可以选择：

- 已经在模板管理中保存的模板；
- “不使用模板”。

选择已有模板后：

- 当前文件立即使用该模板填入映射并生成预览；
- 用户仍可在确认前调整映射；
- 不自动导入，不修改当前货物。

选择“不使用模板”后：

- 所有字段映射保持未选择状态，系统不提供自动映射；
- 用户必须手动选择本次需要的源列；
- 用户完成有效映射后可以把本次配置保存为新模板；
- 保存新模板不会代替确认导入，用户仍需单独点击确认。

模板选择、映射配置和数据预览都在同一个导入确认流程中完成。映射配置和预览同时可见并保持可编辑，不因当前配置有效而自动跳过映射阶段。用户可以在确认前返回模板选择；重新选择后，本次未保存的映射草稿被所选模板配置或空白手动配置替换，预览随之刷新。

### 3.3 检查与调整

用户可以：

- 调整表头所在行和数据开始行；
- 修改标签、名称、长、宽、高、重量、数量等字段的来源列；
- 在“独立尺寸列”和“组合尺寸列”之间切换；
- 选择毫米、厘米或自动识别；
- 调整组合尺寸的长宽高顺序；
- 设置除重量外、源文件缺值时允许使用的可见默认值；
- 在未选择模板时，把完成的有效映射保存为新模板；
- 在选择已有模板并修改配置后，明确选择“更新模板”或“另存为模板”；
- 在确认前返回并重新选择模板。

每次调整后，预览和统计应立即按新配置刷新。用户不需要先离开导入确认或进入模板管理页才能保存、更新或另存当前映射。

### 3.4 确认或取消

#### 确认导入

只有同时满足以下条件时才允许确认：

- 独立尺寸模式已映射长、宽、高，或组合尺寸模式已映射组合尺寸列；
- 当前文件不存在未修正的模板缺列；
- 没有重复映射；
- 没有错误行；
- 至少存在一条可导入货物。

重量映射不是确认导入的前置条件。未映射重量列或已映射重量单元格为空时，系统内部使用 `1 kg`；非空但不可解析、为零或为负数的重量仍属于错误。

用户点击确认后：

1. 本次有效货物整体替换当前货物清单，不与旧货物追加混合。
2. 基于旧货物的自动装箱结果和手动排布均失效，用户需要基于新货物重新装箱或排布。
3. 映射界面关闭。
4. 工作台展示导入日志。
5. 货物清单、标签颜色和后续计算统一使用新数据。

本轮不增加“将替换当前货物”的额外提示或二次确认。确认导入按钮是唯一提交边界；替换行为仍由工作台执行，映射与预览流程只负责产生标准货物结果。

#### 取消导入

用户取消、按 Escape 或关闭映射界面时：

- 当前货物清单不变；
- 当前装箱结果不变；
- 本次待导入数据被丢弃；
- 不显示导入成功。

## 4. 字段映射行为

### 4.1 手动选择与必填标识

选择“不使用模板”时，系统不根据表头自动选择字段。所有映射控件以未选择状态开始，由用户明确指定源列。

映射表单必须在必要字段名称前显示 `*`，并在表单附近说明 `*` 表示完成当前配置所必需的项目：

- 独立尺寸模式：`* 长`、`* 宽`、`* 高`；
- 组合尺寸模式：`* 组合尺寸列`、`* 尺寸顺序`；
- 保存为新模板或另存为模板时：`* 模板名称`。

标签、名称、重量、数量、颜色、可旋转、可堆叠、最大堆叠层数和必须落地不显示必填标识；它们可以来自源列，也可以按本稿规定的默认行为生成。模板已填入的必填映射仍保留 `*`，用于说明业务必要性，而不是表示用户必须再次选择。

### 4.2 必要信息

一条货物要进入清单，必须能得到：

- 有效长、宽、高；
- 有效正重量；未映射或空白重量按内部默认值 `1 kg` 生成；
- 有效正整数数量，或者采用明确的默认数量 `1`。

标签、名称、颜色和装载限制可以来自文件，也可以使用确定性默认行为。除内部重量默认值外，使用会影响用户判断的默认或回退行为时必须在预览中显示。

### 4.3 重复映射

同一源列不能同时代表两个不同业务字段。

例如把 `W` 同时映射为“长”和“宽”时：

- 两个字段均标记冲突；
- 页面说明冲突的源列和目标字段；
- 确认按钮禁用；
- 模板不能保存为有效模板。

系统不能用同一个值生成看似有效的错误尺寸。

### 4.4 独立尺寸列

当长、宽、高分别位于不同列时：

- 每个尺寸可以分别选择源列；
- 每个尺寸可以分别选择毫米、厘米或自动识别；
- 预览同时显示源值和最终毫米值。

### 4.5 组合尺寸列

当一列包含类似 `530×305×310` 的组合尺寸时：

- 用户选择组合尺寸列；
- 用户选择该列的单位；
- 用户选择三个数字分别代表长、宽、高的顺序；
- 预览拆分并显示最终长、宽、高；
- 某一行无法恰好拆出三个有效正数时，该行报错并阻止整批导入。

组合尺寸的单位必须单独可见、可修改，不能依赖已经隐藏的独立尺寸设置。

### 4.6 默认值

默认值用于处理文件没有对应列，或允许为空的单元格。

预期行为：

- 未提供数量时，使用默认数量 `1`，并显示警告；
- 未提供标签时，生成确定性标签，并显示警告；
- 未提供名称时，生成可识别的临时名称，并显示警告；
- 重量映射可选，界面不提供默认重量输入；未映射重量列或已映射重量单元格为空时，系统内部使用 `1 kg`；
- 内部默认重量不作为映射项、模板默认值或预览警告展示；
- 已映射重量列中的非空非法值、零或负数必须报错，不能被 `1 kg` 掩盖；
- 文件中的有效非空值优先于默认值，默认值不能覆盖真实数据。

## 5. 数据预览行为

预览的目的不是展示表格截图，而是让用户判断“原始文件会变成什么货物”。

每条预览至少显示：

- Excel/CSV 中的真实行号；
- 原始标签或名称；
- 原始尺寸、重量和数量；
- 换算后的毫米尺寸；
- 除内部默认重量外，实际采用的可见默认值；
- 当前行状态及原因。

预览默认展示前 5–10 条，同时允许用户知道全文件的统计结果。错误提示使用真实源行号；修改表头行或数据开始行后，行号不能重新从 2 开始计算。重量缺失或空白导致的内部 `1 kg` 不单独显示为默认值或警告，但导入后的标准货物仍持有可用于装箱计算的正重量。

顶部统计固定包含：

- 源数据行数；
- 可导入行数；
- 错误行数；
- 警告行数；
- 跳过行数；
- 厘米换算行数。

## 6. 错误、警告与跳过

| 状态 | 含义 | 是否可确认 | 对当前货物的影响 |
| --- | --- | --- | --- |
| 错误 | 配置或某行数据无法形成合法货物 | 不可确认 | 无影响 |
| 警告 | 数据可导入，但使用了换算、默认值或回退值 | 可以确认 | 确认后按预览结果替换 |
| 跳过 | 空行、标题行、汇总行等非货物数据 | 可以确认 | 不生成货物 |
| 成功 | 数据可直接形成合法货物 | 可以确认 | 确认后按预览结果替换 |

错误行和有效行同时存在时，仍然整批阻止。系统不提供“只导入有效行”，避免用户遗漏货物或重复导入。

典型错误包括：

- 缺少必填尺寸映射；
- 模板引用的列在当前文件中不存在；
- 同一列被重复映射；
- 尺寸或数量无法解析；
- 已映射重量值非空但无法解析、为零或为负数；
- 数量不是正整数；
- 组合尺寸无法拆分；
- 布尔类业务值无法识别；
- 模板名称为空、另存为名称未变化或名称与已有模板重复；
- 模板配置本身不完整或存在映射冲突。

典型警告包括：

- 厘米换算为毫米；
- 数量使用默认值 `1`；
- 标签或名称使用系统生成值；
- 自动单位在没有表头提示时按毫米处理；
- 非法颜色改用系统颜色。

## 7. 模板功能行为

### 7.1 模板是独立功能

模板管理是独立的功能入口，负责维护当前用户可复用的文件识别规则。模板管理支持新建、查看、编辑、重命名和删除；它不负责导入当前文件，也不改变当前工作台货物。

导入文件后的模板选择发生在本次导入确认中：用户直接从模板管理产生的模板列表中选择，或者明确选择“不使用模板”后自行建立映射。

模板保存的是“如何理解一种固定格式的文件”，包括：

- 表头和数据开始位置；
- 字段与源列的对应关系；
- 尺寸模式、单位和顺序；
- 缺值时允许使用的默认值。

模板不保存某次文件的数据，也不会在选择或保存后自动导入。

### 7.2 新建模板

模板管理页是模板新建的独立入口。用户可以不导入货物，直接在模板管理中填写模板名称和识别规则；也可以在模板管理中加载样例文件，辅助选择真实表头。

当用户在本次导入中选择“不使用模板”并完成手动映射后，导入确认界面提供“保存为模板”。用户填写模板名称并保存当前映射后：

- 新模板进入模板管理列表；
- 当前导入确认保留原来的映射和预览；
- 当前新模板成为本次确认中已选中的模板基线；
- 不自动执行导入，用户仍需点击确认导入。

模板必须有唯一名称，并且配置本身有效。独立尺寸模式缺少长、宽或高，组合尺寸模式缺少组合列或尺寸顺序，或存在重复映射时，模板不能保存。重量列不是模板有效性的必需映射。

### 7.3 导入中选择模板

导入确认中的模板选择使用模板管理维护的模板列表。用户选择模板后：

- 页面填入模板中的配置；
- 立即使用当前文件重新生成预览；
- 不自动点击确认；
- 不改变当前货物。

用户可以在确认前切换到另一个模板，或切换为“不使用模板”后从空白状态重新建立映射。切换选择会丢弃本次未保存的映射修改，但不会改变模板管理中的模板内容。

若模板需要的列不在当前文件中：

- 模板仍保持选中，便于用户看出问题；
- 缺失列明确标红；
- 页面列出缺少的列；
- 确认、更新和另存为操作在配置恢复有效前禁用；
- 用户可以改映射后继续，也可以取消。

### 7.4 更新、另存为与保存为模板

- 在模板管理页编辑已存在的模板，保存表示更新该模板；
- 在导入确认中选择已有模板后，未修改配置时不显示需要保存的状态；
- 用户修改模板配置后，页面同时提供“更新模板”和“另存为模板”两个明确动作；
- “更新模板”使用当前有效配置覆盖已选模板，模板名称保持不变；
- “另存为模板”要求输入一个与原名称不同且当前用户下唯一的新名称，保存为新模板并保留原模板；
- 模板配置修改包括字段映射、单位、表头行、数据开始行、尺寸模式、组合尺寸列、尺寸顺序和可见默认值；
- 未选择模板时完成有效映射，使用“保存为模板”创建新模板；
- 保存、更新或另存成功后只更新模板目录和当前保存基线，不执行导入；
- 重名时明确提示名称已存在，不显示成功状态；
- 保存失败时保留当前映射、名称和选择状态，允许重试。

### 7.5 模板管理页

模板管理页是独立入口，支持：

- 查看模板名称和主要配置摘要；
- 新建模板；
- 编辑和重命名模板；
- 删除模板；
- 加载一个样例文件辅助选择表头列。

在模板管理页新建或编辑模板不会打开货物导入，也不会替换当前货物。样例文件只帮助配置模板，不把货物导入工作台。

当用户连续选择两个样例文件时，以最后选择的文件为准。较早文件即使更晚解析完成，也不能覆盖当前样例。样例加载失败时，旧样例提示和列选项应清除，并显示失败原因。

删除模板只删除可复用配置，不删除已经导入的货物。删除请求失败时，模板仍保留在列表中。

### 7.6 本轮不提供的模板能力

本轮不提供“按标签自动合并多行”。系统不会展示一个看似可选、实际没有明确行为的合并选项。若后续需要，应先定义数量、重量和尺寸冲突时的业务规则。

## 8. 标签行为预期

- 文件中有标签时，导入后保留该标签，不截取前缀代替完整 SKU。
- 文件中没有标签时，系统生成稳定且互不重复的标签，并在预览中提示。
- 同一标签在货物清单、装箱、2D、3D、分层、明细和导出中保持一致。
- 同一标签的颜色遵循工作台统一颜色规则。
- 空白或不可用的源标签按“无标签”处理：系统生成新标签并显示警告，不能生成空标签或静默丢失该行。

## 9. 界面与语言

- 模板选择、映射、预览、保存状态、校验错误和模板管理新增文案必须同时接入中文和英文文案源，不在组件中写死文本；
- 中文是本轮视觉与文案验收的优先语言，中文流程必须先达到完整、清晰、无截断；
- 英文流程不得缺少按钮、状态或错误信息，且必须在最终验收前完成同等功能覆盖；
- 必填 `*`、错误颜色和按钮状态不能只依赖文字语言表达，切换语言后语义保持一致。

## 10. 关键验收场景

### 场景 A：解析成功后先选择模板

**给定** 用户选择了可解析文件。
**当** 文件解析完成。
**则** 页面先显示已有模板和“不使用模板”，不显示已经提交的导入结果，也不改变当前货物。

### 场景 B：不使用模板从空白映射开始

**给定** 用户选择“不使用模板”。
**当** 进入映射与预览阶段。
**则** 所有源列映射均为空，不自动选择表头；独立尺寸模式的长、宽、高在字段名前显示 `*`，用户完成手动选择后预览立即刷新。

### 场景 C：映射与预览不会自动跳步

**给定** 当前手动映射或所选模板已经能够形成有效货物。
**当** 预览变为可确认状态。
**则** 映射控件仍然可见、可编辑，页面不会自动跳到不可编辑的独立预览阶段；用户可以返回模板选择。

### 场景 D：重量缺失或空白

**给定** 文件未映射重量列，或映射重量列中的某个单元格为空，其他必要数据有效。
**当** 系统生成标准货物。
**则** 该货物内部重量为 `1 kg`，确认不被阻止；映射表单和预览不显示默认重量输入或默认重量警告。

### 场景 E：非法非空重量

**给定** 已映射重量单元格包含非空非法文本、零或负数。
**当** 系统生成预览。
**则** 真实源行显示重量错误，整批确认被禁用，`1 kg` 默认值不能掩盖错误。

### 场景 F：保存无模板手动映射

**给定** 用户选择“不使用模板”并完成有效手动映射。
**当** 用户输入唯一模板名称并点击“保存为模板”。
**则** 新模板进入目录并成为当前保存基线；导入确认保持打开，当前货物不变，仍需另行确认导入。

### 场景 G：更新已选模板

**给定** 用户选择已有模板并修改字段映射、单位或其他模板配置。
**当** 用户点击“更新模板”。
**则** 系统以当前配置更新原模板，名称和模板 ID 不变；原模板只有在用户点击该明确动作后才变化，且不会执行货物导入。

### 场景 H：将已选模板另存为新模板

**给定** 用户选择已有模板并修改配置。
**当** 用户点击“另存为模板”。
**则** 系统要求输入新的唯一名称；保存成功后创建新模板并保留原模板，当前确认保持打开且不执行导入。空名称、原名称或已有名称均不能显示成功状态。

### 场景 I：无效模板不能保存

**给定** 模板缺少当前尺寸模式所需的映射，或同一源列被映射到多个业务字段。
**当** 用户尝试保存、更新或另存。
**则** 必填字段和冲突字段有明确错误，保存操作被禁用或拒绝，模板目录不发生变化。

### 场景 J：模板与文件不匹配

**给定** 所选模板引用当前文件中不存在的列。
**当** 模板应用到当前文件。
**则** 模板保持选中，缺失列明确标红，确认和模板保存动作被阻止；用户修正映射后可以继续。

### 场景 K：取消不产生隐藏修改

**给定** 工作台已有货物和装箱结果，用户已进入导入确认并调整映射。
**当** 用户取消、按 Escape 或关闭确认。
**则** 当前货物、自动装箱结果和手动排布保持不变，不显示导入成功；只有此前已经明确完成的模板保存动作继续有效。

### 场景 L：确认导入的提交边界

**给定** 预览至少有一条有效货物且没有错误。
**当** 用户点击“确认导入”。
**则** 新货物整体替换当前货物，旧自动结果和手动排布失效；本轮不要求额外替换提示或二次确认。

### 场景 M：模板管理保持独立

**给定** 用户进入模板管理页。
**当** 用户新建、编辑、重命名、删除模板或连续加载样例文件。
**则** 只改变模板目录和页面草稿，最后选择的样例文件拥有权威，操作不打开导入确认、不改变工作台货物；失败操作保留可重试草稿和原模板。

### 场景 N：中文与英文

**给定** 用户分别使用中文和英文。
**当** 完成模板选择、映射、预览、保存、更新、另存和错误修正。
**则** 两种语言都具有完整按钮、状态和错误反馈；中文布局和文案优先达到最终视觉验收标准。

### 场景 O：真实业务文件

- `俄罗斯整托装柜尺寸.xlsx` 通过手动映射或有效模板识别 31 托，保留标签和真实尺寸，并继续满足指定货柜下 31/31 装入验收；
- `越南第十一批6.2海运.xlsx` 通过手动映射或有效模板跳过标题/汇总行，识别组合尺寸、箱数和每箱重量，形成 24 条有效货物记录。

## 11. 完成标准

该功能达到可交付状态时，必须同时满足：

1. 场景 A–O 均有自动化验收覆盖，不沿用与本稿冲突的旧交互断言；
2. 不使用模板时不存在自动映射，必要映射字段具有稳定的 `*` 标识；
3. 内部 `1 kg` 重量规则覆盖未映射和空白两种情况，非法非空重量仍整批阻止；
4. 已有模板的更新与另存为是两个独立、显式、不可混淆的动作；
5. 无效映射、模板缺列、重复映射、重名和保存失败都有可见反馈且不会产生伪成功；
6. 模板保存与货物导入保持两个独立提交动作；
7. 取消、失败和重试不会产生未明确触发的数据修改；
8. 中文和英文功能一致，中文优先完成视觉和文案验收；
9. 两个真实 Excel 夹具按场景 O 的数量和业务含义通过；
10. 标签从导入一直保留到计算、展示和导出。

## 12. 非本轮范围

- AI 或基于表头的自动字段映射；
- 只导入有效行的部分导入模式；
- 多工作表合并导入；
- 按标签自动合并多行；
- 导入时自动开始装箱；
- 未经用户确认自动应用上次模板并覆盖货物；
- 针对已有货物增加替换警告、二次确认或追加/替换模式选择。
