# Excel 导入与模板配置功能行为稿

- 日期：2026-08-19
- 文档类型：产品功能与行为预期
- 状态：修订稿，待确认
- 适用范围：Excel/CSV 导入、字段映射、导入预览、导入模板管理

> 本文只描述用户能做什么、系统应如何反馈以及最终业务结果，不规定代码结构或技术实现。

## 1. 功能定位

Excel 导入用于把外部货物表转换为当前工作台可直接装箱的货物清单。

模板配置用于保存某一种固定表格格式的识别规则，使用户再次导入相同来源的文件时，不需要重新配置表头、字段和单位。

该功能必须解决三个问题：

1. 用户在导入前能看懂系统识别了什么。
2. 错误数据不能以“导入成功”的形式进入货物清单。
3. 已确认的标签、尺寸和业务限制在装箱、2D、3D、分层、明细与导出中保持一致。

## 2. 功能组成

| 功能 | 用户目的 | 系统结果 |
| --- | --- | --- |
| 文件导入 | 选择外部 Excel 或 CSV | 读取文件并进入映射确认，不直接修改货物 |
| 字段映射 | 指定每一列代表什么 | 生成可检查的标准货物预览 |
| 单位设置 | 确认尺寸是毫米还是厘米 | 显示换算后的毫米尺寸 |
| 数据预览 | 检查原始值与导入结果 | 在确认前发现错误、警告和遗漏 |
| 确认导入 | 使用本次识别结果 | 整体替换当前货物清单，并使旧装箱结果失效 |
| 模板保存 | 复用当前识别规则 | 形成当前用户可重复选择的模板 |
| 模板管理 | 新建、编辑、重命名、删除模板 | 保持常用供应商或客户表格格式可维护 |
| 导入日志 | 查看本次处理结果 | 显示成功数、警告、跳过行和换算信息 |

## 3. 用户主流程

### 3.1 选择文件

用户从工作台选择 `.xlsx`、`.xls` 或 `.csv` 文件。

预期行为：

- 系统读取文件后打开“导入映射确认”界面。
- 文件选择本身不改变当前货物清单。
- 系统只读取当前约定的第一个工作表；不会把多个工作表静默合并。
- 文件为空、无法读取、解析超时或超过导入上限时，不进入映射确认，直接显示明确失败原因。
- 超限文件整批拒绝，不截断后伪装为完整导入。

### 3.2 进入映射确认

映射确认界面必须让用户同时看到：

- 当前文件的表头和数据规模；
- 当前选择的模板；
- 每个业务字段对应的源列；
- 尺寸单位和尺寸排列方式；
- 原始数据样例；
- 转换后的货物样例；
- 有效行、错误行、警告行、跳过行和单位换算数量。

系统可以自动建议映射，但建议只用于减少操作，不能自动完成导入。用户始终可以修改建议。

### 3.3 检查与调整

用户可以：

- 调整表头所在行和数据开始行；
- 修改标签、名称、长、宽、高、重量、数量等字段的来源列；
- 在“独立尺寸列”和“组合尺寸列”之间切换；
- 选择毫米、厘米或自动识别；
- 调整组合尺寸的长宽高顺序；
- 设置源文件缺值时可使用的默认值；
- 选择已有模板，或把当前配置保存为模板。

每次调整后，预览和统计应立即按新配置刷新。用户不需要先保存模板才能检查导入结果。

### 3.4 确认或取消

#### 确认导入

- 尺寸来源完整；
- 重量列存在且可用，或用户明确设置了有效默认重量；
- 当前文件不存在模板缺列；
- 没有重复映射；
- 没有错误行；
- 至少存在一条可导入货物。

用户点击确认后：

1. 本次有效货物整体替换当前货物清单，不与旧货物追加混合。
2. 基于旧货物的自动装箱结果和手动排布均失效，用户需要基于新货物重新装箱或排布。
3. 映射界面关闭。
4. 工作台展示导入日志。
5. 货物清单、标签颜色和后续计算统一使用新数据。

当当前货物清单非空时，界面必须明确提示“确认后将替换当前货物”，不能只用含义模糊的“导入”按钮。

#### 取消导入

用户取消、按 Escape 或关闭映射界面时：

- 当前货物清单不变；
- 当前装箱结果不变；
- 本次待导入数据被丢弃；
- 不显示导入成功。

## 4. 字段映射行为

### 4.1 自动建议

系统根据中文、英文和常见业务表头给出初始建议，例如：

- `托盘`、`标签`、`SKU` 可建议为标签；
- `品名`、`货物名称` 可建议为名称；
- `整托重量kg`、`毛重` 可建议为重量；
- `箱数`、`托数` 可建议为数量；
- 带 `cm` 或“厘米”的尺寸列可建议为厘米。

若同一字段存在多个可能来源，系统给出一个建议，但用户必须能看到并修改。数量优先建议实际箱数或托数，不优先选择预计发货件数；重量优先建议单箱或整托重量，不优先选择总重量。

### 4.2 必要信息

一条货物要进入清单，必须能得到：

- 有效长、宽、高；
- 有效正重量；
- 有效正整数数量，或者采用明确的默认数量 1。

标签、名称、颜色和装载限制可以来自文件，也可以使用明确的默认行为。使用默认行为时必须在预览中显示，而不是静默补值。

### 4.3 重复映射

同一源列不能同时代表两个不同业务字段。

例如把 `W` 同时映射为“长”和“宽”时：

- 两个字段均标记冲突；
- 页面说明冲突的源列和目标字段；
- 确认按钮禁用；
- 模板不能保存为有效模板。

系统不能用同一个值生成看似有效的错误尺寸。

### 4.4 独立尺寸列

当长、宽、高分别位于不同列时：

- 每个尺寸可以分别选择源列；
- 每个尺寸可以分别选择毫米、厘米或自动识别；
- 预览同时显示源值和最终毫米值。

### 4.5 组合尺寸列

当一列包含类似 `530×305×310` 的组合尺寸时：

- 用户选择组合尺寸列；
- 用户选择该列的单位；
- 用户选择三个数字分别代表长、宽、高的顺序；
- 预览拆分并显示最终长、宽、高；
- 某一行无法恰好拆出三个有效正数时，该行报错并阻止整批导入。

组合尺寸的单位必须单独可见、可修改，不能依赖已经隐藏的独立尺寸设置。

### 4.6 默认值

默认值用于处理文件没有对应列，或允许为空的单元格。

预期行为：

- 未提供数量时，可使用默认数量 1，并显示警告。
- 未提供标签时，可生成确定性标签，并显示警告。
- 未提供名称时，可生成可识别的临时名称，并显示警告。
- 未映射重量列时，只有用户明确设置了默认重量才可继续。
- 已映射重量列中的空白或非法值不能被默认重量掩盖，必须报错。
- 文件中的有效非空值优先于默认值，默认值不能覆盖真实数据。

## 5. 数据预览行为

预览的目的不是展示表格截图，而是让用户判断“原始文件会变成什么货物”。

每条预览至少显示：

- Excel/CSV 中的真实行号；
- 原始标签或名称；
- 原始尺寸、重量和数量；
- 换算后的毫米尺寸；
- 实际采用的默认值；
- 当前行状态及原因。

预览默认展示前 5–10 条，同时允许用户知道全文件的统计结果。错误提示使用真实源行号；修改表头行或数据开始行后，行号不能重新从 2 开始计算。

顶部统计固定包含：

- 源数据行数；
- 可导入行数；
- 错误行数；
- 警告行数；
- 跳过行数；
- 厘米换算行数。

## 6. 错误、警告与跳过

| 状态 | 含义 | 是否可确认 | 对当前货物的影响 |
| --- | --- | --- | --- |
| 错误 | 配置或某行数据无法形成合法货物 | 不可确认 | 无影响 |
| 警告 | 数据可导入，但使用了换算、默认值或回退值 | 可以确认 | 确认后按预览结果替换 |
| 跳过 | 空行、标题行、汇总行等非货物数据 | 可以确认 | 不生成货物 |
| 成功 | 数据可直接形成合法货物 | 可以确认 | 确认后按预览结果替换 |

错误行和有效行同时存在时，仍然整批阻止。系统不提供“只导入有效行”，避免用户遗漏货物或重复导入。

典型错误包括：

- 缺少尺寸或重量来源；
- 模板引用的列在当前文件中不存在；
- 同一列被重复映射；
- 尺寸、重量或数量无法解析；
- 数量不是正整数；
- 组合尺寸无法拆分；
- 布尔类业务值无法识别。

典型警告包括：

- 厘米换算为毫米；
- 数量使用默认值 1；
- 标签或名称使用系统生成值；
- 自动单位在没有表头提示时按毫米处理；
- 非法颜色改用系统颜色。

## 7. 模板功能行为

### 7.1 模板用途

模板保存的是“如何理解一种固定格式的文件”，包括：

- 表头和数据开始位置；
- 字段与源列的对应关系；
- 尺寸模式、单位和顺序；
- 缺值时允许使用的默认值。

模板不保存某次文件的数据，也不会在选择后自动导入。

### 7.2 新建模板

用户可以在两处新建模板：

- 导入映射界面：把当前已经调整好的配置保存下来；
- 模板管理页：先配置规则，必要时加载样例文件辅助选择列。

模板必须有名称，并且配置本身能够形成合法货物。只有名称、没有有效尺寸或重量来源的模板不能保存。

模板保存成功后：

- 出现在当前用户的模板列表中；
- 当前映射界面保持原配置；
- 不自动执行导入。

### 7.3 选择模板

用户选择模板后：

- 页面填入模板中的配置；
- 立即使用当前文件重新生成预览；
- 不自动点击确认；
- 不改变当前货物。

若模板需要的列不在当前文件中：

- 模板仍保持选中，便于用户看出问题；
- 缺失列明确标红；
- 页面列出缺少的列；
- 确认按钮禁用；
- 用户可以改映射后继续，也可以取消。

### 7.4 更新与另存为

- 编辑已选模板且名称不变时，保存表示更新该模板。
- 修改名称后保存表示新建另一份模板，原模板保留。
- 重名时明确提示名称已存在，不显示成功状态。
- 保存失败时保留用户当前填写内容，允许重试。

### 7.5 模板管理页

模板管理页支持：

- 查看模板名称和主要配置摘要；
- 新建模板；
- 编辑和重命名模板；
- 删除模板；
- 加载一个样例文件辅助选择表头列。

样例文件只帮助配置模板，不把货物导入工作台。

当用户连续选择两个样例文件时，以最后选择的文件为准。较早文件即使更晚解析完成，也不能覆盖当前样例。样例加载失败时，旧样例提示和列选项应清除，并显示失败原因。

删除模板只删除可复用配置，不删除已经导入的货物。删除请求失败时，模板仍保留在列表中。

### 7.6 本轮不提供的模板能力

本轮不提供“按标签自动合并多行”。系统不会展示一个看似可选、实际没有明确行为的合并选项。若后续需要，应先定义数量、重量和尺寸冲突时的业务规则。

## 8. 标签行为预期

- 文件中有标签时，导入后保留该标签，不截取前缀代替完整 SKU。
- 文件中没有标签时，系统生成稳定且互不重复的标签，并在预览中提示。
- 同一标签在货物清单、装箱、2D、3D、分层、明细和导出中保持一致。
- 同一标签的颜色遵循工作台统一颜色规则。
- 空白或不可用的源标签按“无标签”处理：系统生成新标签并显示警告，不能生成空标签或静默丢失该行。

## 9. 关键验收场景

### 场景 A：标准文件直接确认

**给定** 文件表头可被正确识别，所有数据合法。
**当** 用户选择文件并检查预览。
**则** 映射建议正确、错误数为 0，用户确认后当前货物被新数据替换，导入日志显示成功数量。

### 场景 B：取消导入

**给定** 工作台已有货物和装箱结果。
**当** 用户选择新文件后取消映射确认。
**则** 原货物和原装箱结果保持不变，不显示导入成功。

### 场景 C：替换当前货物

**给定** 工作台已有货物。
**当** 新文件预览无错误。
**则** 确认前明确提示将替换当前货物；用户确认后旧货物不再保留，旧的自动装箱结果和手动排布均失效。

### 场景 D：有效行与错误行混合

**给定** 文件中既有合法货物，也有非法重量或尺寸。
**当** 系统生成预览。
**则** 显示真实错误行号，确认按钮禁用，不导入任何一行，当前货物不变。

### 场景 E：只有警告

**给定** 文件缺少数量，但其他数据合法。
**当** 系统采用默认数量 1。
**则** 预览显示警告和最终数量，用户仍可确认。

### 场景 F：复用模板

**给定** 用户已经保存某供应商模板。
**当** 再次导入相同格式文件并选择该模板。
**则** 映射和单位自动填入，预览按新文件重新计算，仍需用户确认。

### 场景 G：模板与文件不匹配

**给定** 模板引用了当前文件没有的列。
**当** 用户选择该模板。
**则** 缺失列明确显示，确认被阻止，用户可调整映射或取消。

### 场景 H：组合尺寸为厘米

**给定** 组合尺寸列值为 `53×30.5×31`，单位为厘米。
**当** 用户选择组合尺寸模式和厘米。
**则** 预览显示 `530×305×310 mm`，并显示换算提示。

### 场景 I：真实业务文件

- `俄罗斯整托装柜尺寸.xlsx` 导入后识别 31 托，并保留标签和真实尺寸；指定货柜下继续满足 31/31 装入验收。
- `越南第十一批6.2海运.xlsx` 能跳过标题/汇总行，识别组合尺寸、箱数和每箱重量，形成 24 条有效货物记录。

## 10. 完成标准

该功能达到可交付状态时，用户应能确认以下事实：

1. 选择文件不会直接改变货物。
2. 所有识别结果在确认前可见。
3. 错误行会阻止整批导入。
4. 警告会说明系统采用了什么值。
5. 确认导入会明确替换当前货物并使旧结果失效。
6. 模板只预填规则，不自动导入。
7. 模板缺列、重复映射和保存失败都有可见反馈。
8. 标签从导入一直保留到计算、展示和导出。
9. 两个真实 Excel 夹具按既定数量和业务含义通过。
10. 取消、失败和重试不会产生隐藏的数据修改。

## 11. 非本轮范围

- AI 自动决定最终字段映射；
- 只导入有效行的部分导入模式；
- 多工作表合并导入；
- 按标签自动合并多行；
- 导入时自动开始装箱；
- 未经用户确认自动应用上次模板并覆盖货物。
