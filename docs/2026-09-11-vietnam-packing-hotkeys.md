# 越南模板装箱与手动微调优化

用户最终确认的截图场景：越南第十一批 Excel，保存的导入模板，20GP，数量优先。

## 现状与根因

当前分支已包含 8 月的 3D 焦点保持和报告导航修复。本次先跑真实 Canvas 选箱，再补齐“保存模板 → 再次导入 → 装箱 → 继续手动”的完整路径，未复现新的 Delete/M 失效。原接口仍允许上层用导航状态禁用已挂载的编辑器，这是历史故障入口。

数量优先的剩余间隙不是封闭空腔。旧实现的 `internalNotchVolume=0` 仍允许两侧有货物、顶部连通的长槽。只调整前沿排序会降低件数；整体平移支撑连通组也没有缩小最大槽。有效改良需要保留下层、重新选择上层货物块。

## 最终改动

- 工作区挂载即注册快捷键，卸载即清理；删除 `hotkeysEnabled` 和假导航参数。保留输入框保护、工作区外交互隔离和最新选中箱体分发。
- `packingGapRepair.ts` 负责重建上层候选的货物余量、重量、EMS 和支撑索引。保留的箱体位于切分高度以下，其全部支撑也被保留；新箱体继续用原可行性检查。
- 数量主搜索完成后，最多尝试四个完整上层候选。仅接受件数不减、最大货物间槽缩小、封闭空腔不增加的方案。合格候选仍按现有数量目标比较。
- 体积模式和已全部装入的方案不运行该修复。最终标签、层级、作业顺序、诊断仍通过原统一结果生成流程。
- 修复 ESLint 扫入嵌套 worktree 的配置问题，规则保持不变。

## 实测结果

| 场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 越南 20GP 数量优先件数 | 482 | 483 |
| 已装体积 | 28.468091 m³ | 29.1322915 m³ |
| 最大货物间槽指标 | 800 mm | 500 mm |
| 封闭空腔指标 | 0 | 0 |
| 越南 20GP 体积优先件数 | 473 | 473 |
| 越南 40HQ 两模式件数 | 864 | 864 |
| 俄罗斯夹具件数 | 31 | 31 |

间隙指标采用现有 50 mm 网格采样。结果是有界改良，仍有剩余空隙，不是全局最优证明。新布局的支撑风险代理值从 152456500 增到 460252750；真实支撑比例、重叠、边界和堆叠约束必须单独通过，不声称运输稳定性改善。

受保护契约生成器确认只有越南 20GP 数量契约发生正向变化，其余四个契约哈希完全不变。未使用允许回归选项。

## 验证记录

- 修改前的定向测试按 500 mm 上限失败，观察到 800 mm；同一测试在集成后通过，并检查数量守恒、碰撞、边界、堆叠和错误诊断。
- 新增上层修复单测 5 项，以及工作区生命周期单测 3 项。
- 完整越南保存模板流程验证真实 3D 点选、M、Delete、Backspace、撤销、池余量守恒、输入框与导航隔离，定向通过。
